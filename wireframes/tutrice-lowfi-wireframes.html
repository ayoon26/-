Squirreled Away (Tutrice) — Low-Fidelity Mobile Wireframes
21 screens, one continuous happy-path story: onboarding via Google Calendar → confirming detected students → reviewing Sarah Kim's AI-built Student Memory → Today → preparing for and recording a lesson → automatic memory update → manually adding a parent message → confirmed memory update. Grayscale, 390×844 mobile frames, arranged in 4 rows in story order. Annotations sit below each frame.
Acorn placeholderbeside every student name (grayscale, uncolored). Sarah's is labeled "Sarah's acorn."
Badgessolid = status/confidence (e.g. "New," "High confidence"); outline = neutral tag.
Source labelssmall gray text under AI-derived content: Google Calendar · Parent message · Lesson note · Lesson recording.
Checkboxesfilled = selected for saving; empty = detected but not yet accepted.
Sticky bottom barprimary button always full-width black; secondary action is text-only beneath it.
